✓ Spíž

Naskenovat kód

Namiř foťák na čárový kód. Funguje na PC, iOS i Androidu (potřebuje povolení kamery a HTTPS – GitHub Pages ho má).

Po načtení kódu se vyplní formulář níže. Můžeš dopsat datum spotřeby a uložit.

Ruční zadání položky

Hvězdička = povinné. Bez data spotřeby položku uložit nepůjde.

Data na webu

Aplikace umí stáhnout nejnovější inventář ze souboru data.json na webu a naopak tvůj aktuální inventář na web nahrát.

Stáhnout z webu

Načte data.json uložený vedle aplikace na GitHub Pages.

Sloučit = doplní/aktualizuje položky. Nahradit = přepíše tvůj inventář verzí z webu.

Nahrát na web (GitHub)

Zapíše aktuální inventář přímo do data.json v tvém repozitáři. Nejdřív vyplň přístup v Nastavení.

Bez GitHubu můžeš data přenést i ručně: dole je Export souboru data.json, který v repozitáři nahradíš / commitneš.

Upozornění na spotřebu

Systémová oznámení
Zapne upozornění mimo aplikaci (dle prohlížeče).
Na iPhonu fungují oznámení jen po přidání na plochu (Sdílet → Přidat na plochu) a v iOS 16.4+. Automatická oznámení „na pozadí“ nejsou u statického webu zaručená — nejspolehlivěji se zkontroluje při otevření aplikace.

Skenování

Web (GitHub) synchronizace

Vyplň, jen když chceš nahrávat přímo z aplikace. Token se ukládá lokálně v tomto prohlížeči.

Vytvoř si fine-grained token s právem Contents: Read and write jen pro tento repozitář. Token je uložený pouze v tomto prohlížeči (localStorage) — nesdílej zařízení, na kterém ho máš.
